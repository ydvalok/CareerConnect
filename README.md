# CareerConnect 💼

CareerConnect is a responsive job portal built using React.js, JavaScript, HTML, CSS, and Bootstrap. It helps users explore job opportunities, search and filter jobs, view job details, and save their favorite jobs.

## ✨ Features

- 🔍 Search jobs by keyword
- 🏢 Filter jobs by category or location (based on implemented filters)
- 📄 View detailed job descriptions
- ❤️ Save and unsave favorite jobs
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap 5
- React Router
- Vite

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd CareerConnect
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 📂 Project Purpose

This project was built to practice React.js, responsive web design, component-based development, and job listing functionality.
